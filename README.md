# shared-makefiles
Shared/reusable makefiles

## Available files

Include only what you need in your project's Makefile, e.g. `include yaml.mk`.

| File           | Targets                        | Description                          |
|----------------|---------------------------------|---------------------------------------|
| `yaml.mk`      | `format-yaml`, `lint-yaml`      | Format and lint YAML files            |
| `makefile.mk`  | `format-makefile`, `lint-makefile` | Format and lint Makefiles          |
